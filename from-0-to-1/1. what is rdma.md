# RDMA 技术简介

RDMA（Remote Direct Memory Access，远程直接内存访问）是一种允许一台计算机直接读写另一台计算机内存，而**无需对方 CPU 或操作系统参与**的网络数据传输技术。

## 核心原理：如何实现“绕过”？

传统网络传输（如 TCP/IP）需要 CPU 多次介入：数据从网卡到内核缓冲区，再经协议栈处理，最后拷贝到用户程序，延迟高且消耗 CPU。RDMA 通过三项关键技术改变了这一路径：

- **内核旁路**：应用程序直接与网卡交互，数据不再经过操作系统内核的网络协议栈，省去了用户态与内核态切换的开销。
- **零拷贝**：网卡直接从应用程序内存读取数据发送，或直接将收到的数据写入应用程序内存，无需在内存缓冲区之间来回搬运。
- **CPU 卸载**：整个数据传输过程由 RDMA 网卡（硬件）独立完成，本地和远端的 CPU 均不参与数据搬运，从而释放算力用于其他计算任务。

## 主要优势与代价

- **优势**：带来极高的带宽、极低的延迟（可低至微秒级）以及更确定的性能表现，非常适合高性能计算、AI 训练、分布式存储等场景。
- **代价**：对网络环境要求苛刻。传统 TCP/IP 能容忍丢包，而 RDMA 通常要求网络**基本无损**（不丢包），否则性能会急剧下降。因此，部署 RDMA 往往需要配套支持无损以太网（如 PFC、ECN）的交换机和专用网卡，配置和管理比普通网络更复杂。

## 主流实现方式

目前主要有三种技术路线，其中 **RoCEv2** 在数据中心最为流行：

1. **InfiniBand (IB)**：专为 RDMA 设计的网络，性能最佳，但需要专用的网卡和交换机，成本高且不兼容以太网。
2. **RoCE (RDMA over Converged Ethernet)**：在以太网上承载 RDMA。**RoCEv2** 版本支持 IP 路由，兼容标准以太网交换机，性价比高，是当前数据中心部署最广泛的方案。
3. **iWARP**：基于 TCP/IP 实现 RDMA，能利用现有标准以太网基础设施，无需无损网络，但性能和实现复杂度上通常不占优势。
